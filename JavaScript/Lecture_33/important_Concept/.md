# Important Concepts

1. Shallow Copy
   → {...obj}
   → top-level copy, nested references shared

2. Deep Copy
   → structuredClone(obj)
   → independent nested objects

3. Constructor Function
   → function Student() {}
   → new Student()

4. Prototype
   → shared properties/methods
   → prototype chain

5. Class
   → cleaner syntax for constructor/prototype system

6. Getter
   → get property

7. Setter
   → control property assignment

8. Object.seal()
   → modify ✅
   → add ❌
   → delete ❌

9. Object.freeze()
   → modify ❌
   → add ❌
   → delete ❌

10. JSON.stringify()
    → Object → JSON string

11. JSON.parse()
   → JSON string → Object
